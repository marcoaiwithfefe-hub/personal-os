# Context

Identity and context files: who the operator is, not what they're working on (that's `Projects/`) and not what happened today (that's `Daily/`).

## me.md

Read silently at the start of every session, first response, no announcement. Holds the operator's identity, working style, goals, and communication preferences, the profile every other file assumes but never restates.

## Rules

- `me.md` is the single authoritative copy of identity and preferences. Never duplicate those facts into another note, i.e. if something changes, it changes here and only here.
- See `me.md` for the section template and a fictional filled example.
