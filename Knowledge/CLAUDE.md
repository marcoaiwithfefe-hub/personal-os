# Knowledge

Home for domain knowledge on any subject you track, i.e. not identity (`Context/`), not a dated log (`Daily/`), not a specific initiative (`Projects/`).

## Structure

One subfolder per domain, e.g. `Knowledge/spanish/`, `Knowledge/bakery/`. One note per topic inside that subfolder.

## Rules

- Don't pre-create empty domain subfolders. Create one the first time you actually have a note to put in it.
- Each note stands alone: readable without needing the note before or after it.
- Wikilink between related notes so a domain accumulates its own web instead of a flat pile of unrelated files.
