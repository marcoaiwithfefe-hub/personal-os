# Daily

One file per day: `YYYY-MM-DD.md`. Write it at the end of a session that produced meaningful work, i.e. skip pure Q&A or casual chat that added nothing new.

## Structure

```markdown
## Focus
## Progress
## Open loops
```

5 to 10 bullets total is the sweet spot: long enough to reconstruct the day, short enough that you'll actually read it back.

## Rules

- Wikilink every entity mentioned, i.e. projects, domains, people, other notes.
- An open loop that's still open the next day gets pulled into that day's file too, rather than left buried in an old one.
- See `2025-01-01-example.md` for a fictional worked example.
